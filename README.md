# 任务通知

在 DeepSeek Harness 里，需要你介入或任务停下来时弹一条系统通知。通知来源是
**DeepSeek Harness 应用本身**，点击通知会聚焦应用并直接切回那个任务。

## 安装

1. 克隆或下载本仓库到本地任意目录。
2. 打开「设置 › 插件」，选择「添加插件」，选中该目录。
3. 刷新窗口（⌘R），客户端半随之加载。

需要 DeepSeek Harness 桌面版（Electron 44 / 应用 0.2.2 起）。Dock 徽标仅 macOS 有效。

## 会出现哪些通知

| 场景 | 正文 |
| --- | --- |
| 工具请求授权 | `工具 Bash 需要你的授权` |
| 有问题待回答 | `有问题等你回答：要继续覆盖配置吗？` |
| 有方案待确认 | `有一份计划等你确认` |
| 回合正常完成 | `任务已完成 · 目录名` |
| 回合出错 | `任务出错：原因` |
| 手动停止 | `任务已中止 · 手动停止` |
| 上级会话结束 | `任务已中止 · 上级会话结束` |
| 输出达到上限 | `任务中断 · 输出达到上限` |
| 回合被阻塞 | `任务被阻塞，需要你处理` |
| 上次运行未正常结束 | `任务中断 · 上次运行未正常结束` |

标题统一是会话名（如「修复登录超时」；没有标题时用「DSH 任务提醒」）。
正文跟随界面语言：中文界面显示中文，英文界面显示英文。

## Dock 未读徽标

任务跑完或等你确认时，程序坞图标上显示未读会话数：

- 数字 = 跑完还没打开过的会话 + 正等你授权/回答/确认的会话；
- 打开那个会话即视为已读，数字自动减少；全部读完徽标消失；
- 子 Agent 会话不计入——它们不能在主区单独打开，计入会产生清不掉的数字；
- 超过 99 显示 `99+`；设置里可以单独关掉。

未读是内存态：刷新窗口或重启应用后徽标清零。

## 设置

「设置 › 通用」里有两个开关，改动立即生效并写进 Host 的设置文档：

| 开关 | 关掉之后 |
| --- | --- |
| 任务结束提醒 | 任务停下时不再弹通知（完成、出错、中止都不弹） |
| 待确认提醒 | 授权、提问、方案确认时不再弹通知 |
| Dock 未读徽标 | 程序坞图标上不再显示未读数量 |

三个开关默认都开启；彼此独立，关掉其中一个不影响另一个。

## 什么时候提醒

- 需要你介入的提醒来自会话的待确认状态，同一请求只提醒一次；回答后若又出现新请求会再次提醒。
- 结束提醒只在会话真正回到空闲时发出，追问、工具重试、子 Agent 归队都不会提前提醒。
- 正看着某个会话时不为它弹窗；应用在前台但看的是别的会话，仍会提醒。
- 待确认请求在应用里显示过但没处理时，离开应用会补一次提醒；同一请求只补一次。
- 子 Agent 会话不提醒。

## 实现方式

宿主半不注册任何监听，行为全在客户端半：

- 订阅客户端的会话状态（`uiSession.sessionStatus`），比较前后快照得出「出现待确认请求」与「运行中→空闲」两件事；
- 用会话目录行上的 `retainedBy.mainView` 判断当前看的是哪个会话，据此决定要不要打扰；
- 结束原因从该会话事件窗口里最近一条 `turn/end` 读取，因此能区分完成、出错、中止、输出达上限等情况；
- 通知文案通过客户端 locale 服务取当前界面语言的词典，插件不写死文案；
- 用页面的 `Notification` 弹出，因此桌面端通知归属应用本身，而不是脚本宿主；
- 点击时调用客户端的会话导航 `uiWorkspace.openSession()` 切回该会话；
- 保留未关闭的通知引用，避免对象被回收后点击失效；
- 监听窗口失焦与页面隐藏，为仍在等待的请求补一次提醒；
- 三个开关声明为宿主插件的 volatile 配置，经 Host 设置服务投影给客户端，
  客户端每次提醒前读当前值，因此设置页改动无需刷新；
- Dock 徽标用页面的 `navigator.setAppBadge()`，Electron 在浏览器进程里把它映射成
  `app.dock.setBadge()`；未读数直接来自 DSH 的 `completionUnread` 与待确认状态。

## 限制

- 结束原因读自该会话在客户端的事件窗口，只有仍被客户端持有的会话才有窗口可读。
  窗口不可读时（例如刚连上、历史尚未加载）退回 Host 转发的错误信息；仍无信息时显示
  「任务已完成」。因此这类情况下被中止的回合可能仍显示为完成。
- 系统通知由应用转发。若在「系统设置 › 通知」里禁用了该应用，提醒不会出现，
  但会话本身不受影响。
- 应用未运行时不会提醒（此时也没有任务在跑）。
- 设置行由客户端半注册；页面还没加载新版插件时，设置页里看不到这些开关。
- 未读数量不落盘：刷新窗口、重启应用或重载插件后徽标归零。
- Dock 徽标只有 macOS 有；其它平台会静默跳过。
- 提示音跟随系统对该应用的通知设置，插件不做单独控制。
